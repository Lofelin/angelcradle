# 需求：子宫（Womb）

## 1. 子宫是什么

子宫是一个独立模块。输入种子（家族基因图谱），输出婴儿数据。
子宫不知道摇篮的存在，不关心婴儿将来叫什么、怎么成长。它只管生。

## 2. 种子

种子是一个 YAML 文件，描述家族基因图谱。种子里没有婴儿的名字——
名字是将来在摇篮里被赋予的，不是出生时自带的。

```yaml
family:
  father:
    traits: [严谨, 逻辑驱动, 不善表达]
  mother:
    traits: [敏感, 直觉强, 善于共情]
  paternal_grandfather:
    traits: [沉默寡言, 观察力强]
  maternal_grandmother:
    traits: [乐观, 健谈, 好奇心旺盛]
```

- `family`：至少一个成员，每个成员有 `traits` 列表
- 成员关系不限定，用户可自定义

**验收标准：**

- 缺少 family 或 family 为空 → 拒绝
- 成员缺少 traits 或 traits 为空 → 拒绝

## 3. 孕育过程

1. 解析种子 YAML
2. 构造 prompt，将家族基因交给 LLM 做遗传表达
3. 调用一次 LLM → 输出遗传表达结果（先天倾向）+ 第一声啼哭（初始自我叙事）
4. 组装婴儿数据，分配编号，返回

同一颗种子每次孕育结果不同——基因表达是概率性的。

**验收标准：**

- 有效种子 → 调用一次 LLM → 返回婴儿数据
- LLM 调用失败 → 报错，不产出任何东西

## 4. 婴儿数据

婴儿没有名字，只有编号。编号格式：`AC-YYYYMMDD-XXXX`（AC = Angel Cradle，
日期 + 四位序号）。

```json
{
  "id": "AC-20260401-0001",
  "born_at": "2026-04-01T12:00:00Z",
  "genes": {
    "family": {
      "father": { "traits": ["严谨", "逻辑驱动", "不善表达"] },
      "mother": { "traits": ["敏感", "直觉强", "善于共情"] }
    },
    "expression": ["对模糊信息有天然的不安", "倾向用结构化方式理解世界", "共情能力被压抑但存在"]
  },
  "first_cry": "我刚刚醒来。周围什么都没有..."
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 婴儿编号，子宫自动分配 |
| `born_at` | string (ISO 8601) | 出生时间 |
| `genes` | object | 基因数据：family（原始输入）+ expression（遗传表达结果） |
| `first_cry` | string | 第一声啼哭，LLM 生成的初始自我叙事 |

婴儿数据到此为止。没有 journal、stances、relationships——那些是摇篮的事。

## 5. 子宫的边界

子宫只做：
- 解析种子
- 调用 LLM 做遗传表达
- 组装婴儿数据并返回

子宫不做：
- 命名（摇篮的事）
- 持久化存储（摇篮的事）
- 对话（摇篮的事）
- 成长（摇篮的事）

子宫的输出是婴儿数据（Python 对象或 dict），不是文件。
谁来把婴儿放进摇篮、怎么放，子宫不管。
