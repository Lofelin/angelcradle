# 需求：摇篮（Cradle）

## 1. 摇篮是什么

摇篮是子宫和世界之间的桥梁。输入子宫产出的 Baby 数据，输出一个具备语言、自我意识和社交能力的独立个体。

摇篮模拟真实的婴儿成长过程——从只会哭到能说出"我自己来"。

## 2. 入摇篮

将子宫产出的 Baby 放入摇篮时，系统从 `gestation_log` 编译身份约束：
- 感官画像（各通道灵敏度 0-1，主导/薄弱感官）
- 唤醒基线（high/moderate/low）
- 原始反射（从 early_neural 阶段提取）
- 本能回路（从 late_neural 阶段提取）
- 气质萌芽（从 fetal_movement 阶段提取）
- 先天倾向（从 birth 阶段的 tendencies）
- 行为约束（LLM 编译或规则降级）

身份约束一旦编译，终身不变。

**验收标准：**
- 有效 Baby ID → 编译身份 → 创建初始状态 → 持久化
- 已在摇篮中的 Baby → 拒绝重复入住
- 不存在的 Baby ID → 报错

## 3. 12 个成长阶段

| # | 名称 | 年龄 | 表达形式 | 关键能力 |
|---|------|------|---------|---------|
| 0 | 新生儿期 | 0-1月 | 只能哭 | 原始反射、哭声沟通 |
| 1 | 感知觉醒 | 1-3月 | 咿呀+注视 | 社会性微笑、视觉追踪 |
| 2 | 身体发现 | 3-6月 | 咿呀+伸手 | 抓握、翻身、笑 |
| 3 | 客体恒存 | 6-9月 | 手势+指向 | 物体永恒性、陌生人焦虑 |
| 4 | 移动革命 | 9-12月 | 手势+原词 | 爬行、指向、意图性行为 |
| 5 | 第一个词 | 12-18月 | 单词+手势 | 第一批词语、行走 |
| 6 | 语言爆发 | 18-24月 | 双词句 | 双词句、假装游戏、自我认知 |
| 7 | 为什么期 | 2-3岁 | 简单句子 | 完整句子、因果追问 |
| 8 | 社交萌芽 | 3-4岁 | 叙事 | 同伴意识、角色扮演、道德感 |
| 9 | 规则理解 | 4-5岁 | 推理 | 规则理解、边界试探 |
| 10 | 抽象起步 | 5-6岁 | 推理 | 类比思维、时间概念 |
| 11 | 独立宣言 | 6-7岁 | 独立表达 | 独立观点、自我主张 |

**验收标准：**
- 每个阶段的表达形式严格约束 LLM 输出格式
- 能力按阶段递进解锁，不可跳级
- 前一阶段的能力在后续阶段保持

## 4. 保姆系统

保姆是自动模拟引擎，每个阶段运行一次：

1. **日常事件**（规则引擎，0 次 LLM）：进食、睡眠、不适、日常声响、触碰、玩具、散步
2. **环境事件**（批量 1 次 LLM/阶段）：雷暴、音乐、宠物、镜子、陌生人、争吵等
3. **关键事件**（1 次 LLM/事件）：高烧、持续哭泣、第一次摔倒、第一个词、噩梦、第一次说不等

每个事件通过婴儿的感官画像过滤，同一事件对不同婴儿产生不同反应。

**验收标准：**
- 日常事件不调用 LLM
- 环境事件的反应必须反映感官画像差异
- 关键事件必须暂停等待父母

## 5. 父母介入

用户作为父母，在关键事件时被通知，选择行为：
- 安抚 / 不干预 / 教导 / 选择 / 命名

父母行为被追踪为画像（responsiveness, intervention_style, teaching_frequency, emotional_tone），影响婴儿依恋类型（secure/anxious/avoidant）。

**验收标准：**
- 关键事件提供 2-4 个选项
- 父母选择影响婴儿状态（恐惧/偏好/安慰源/依恋）
- 父母画像随介入累积更新

## 6. 进入世界

能力检查，非阶段自动毕业：
- **硬性条件**：语言表达、自我概念、心智理论、情绪调节
- **软性条件**：好奇心、社交技能、韧性、独立性

未达标也可进入世界，但带着未完成的发展。

## 7. 摇篮的边界

摇篮只做：
- 接收子宫产出的 Baby
- 模拟成长过程
- 响应父母介入
- 输出可进入世界的个体

摇篮不做：
- 自由对话（世界的事）
- 社交网络（世界的事）
- 知识学习（世界的事）

## 8. 六大维度增强（v2）

在基础摇篮功能上增加六个发育维度：压力与回退（高压下已掌握能力临时丢失，恢复后获韧性加成）、喂养与睡眠（母乳→辅食→自主进食，睡眠回退期）、情绪调节（发脾气频率曲线、情绪词汇、共情等级、想象伙伴）、体格发育（身高/体重/出牙/如厕/精细运动）、多照护者（每人独立画像，影响各自依恋类型）、动态事件权重（阶段+状态调制事件概率）。事件库扩展至 48 种。
